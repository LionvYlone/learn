# Python 学习工程

零基础 24 周计划的练习仓库。所有代码都在这里，不另建文件夹。

## 每天怎么开始

1. 用 VS Code 打开这个文件夹（`code .`）
2. 右下角确认解释器是 `.venv`
3. 打开当天目录，写代码，运行

## 目录约定

```
learn/
  day01/        第 1 天练习
  day02/        第 2 天练习
  ...
  .venv/        虚拟环境（不要提交，已在 .gitignore 里）
```

## 本地运行

```powershell
.\.venv\Scripts\python.exe day01\hello.py
```
